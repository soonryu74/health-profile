# 지역 건강프로파일 대시보드

전국 229개 시군구 건강지표 시각화 대시보드입니다.

**https://health-profile.kr**

## 이 저장소에 대하여

배포 전용 저장소입니다. 단일 HTML 파일 하나(`index.html`)로 구성되며,
빌드 산출물은 [soonryu74/soonryu74.github.io](https://github.com/soonryu74/soonryu74.github.io)
의 `health-dashboard/` 에서 생성해 이곳으로 거울 배포합니다.
소스·수집 스크립트·방법론 문서는 모두 그쪽에 있습니다.

같은 내용이 https://soonryu74.github.io/health-dashboard/ 에서도 제공됩니다.
